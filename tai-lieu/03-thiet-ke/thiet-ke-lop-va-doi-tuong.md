# Thiết kế lớp và đối tượng

Backend starter chuẩn bị các nhóm lớp:

- Model: sinh viên, giảng viên, môn học, lịch học, đăng ký.
- DTO: request/response cho API đăng ký.
- Service: nơi đặt nghiệp vụ ở phase sau.
- Repository: nơi thao tác dữ liệu JSON ở phase sau.
- Validator: nơi kiểm tra điều kiện đăng ký.

Thiết kế chi tiết UML sẽ được bổ sung khi nhóm khóa yêu cầu nghiệp vụ.
