# Thiết kế giao diện

Frontend là ứng dụng React single-page theo layout dashboard:

- Trang đăng nhập thiết kế hai mảng: giới thiệu hệ thống và form đăng nhập.
- Sau đăng nhập có sidebar, header, nội dung chính.
- Các màn hình chính: Dashboard, Đăng ký môn học, Môn đã đăng ký, Thời khóa biểu, Thông báo, Hồ sơ.
- Modal: chi tiết môn học và xác nhận đăng ký.

Dashboard, Course, Registration, Timetable và Profile lấy dữ liệu từ API backend. Notifications hiện là dữ liệu local demo ở frontend.
