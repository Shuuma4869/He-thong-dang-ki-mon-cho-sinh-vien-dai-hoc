# Hướng dẫn chạy frontend

Yêu cầu:

- Node.js 20 trở lên.
- npm 10 trở lên.

Chạy frontend:

```powershell
cd frontend
npm install
npm run dev
```

Kiểm tra frontend:

```powershell
cd frontend
npm run typecheck
npm run build
```

Frontend hiện dùng mock data và chưa cần backend để chạy giao diện starter.
