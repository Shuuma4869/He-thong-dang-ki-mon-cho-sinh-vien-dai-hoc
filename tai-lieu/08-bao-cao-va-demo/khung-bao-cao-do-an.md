# Khung báo cáo đồ án

## Chương 1. Mở đầu

Trình bày lý do chọn đề tài, mục tiêu, đối tượng sử dụng và phạm vi.

## Chương 2. Phân tích và thiết kế

Trình bày yêu cầu chức năng, quy tắc nghiệp vụ, class diagram, use case, luồng đăng ký/hủy.

## Chương 3. Cài đặt hệ thống

Trình bày frontend, backend, repository JSON, validator chain và API.

## Chương 4. Kiểm thử và demo

Trình bày test class, test case chính, kết quả build/test và ảnh demo.

## Chương 5. Kết luận

Nêu kết quả đạt được, giới hạn và hướng phát triển.
