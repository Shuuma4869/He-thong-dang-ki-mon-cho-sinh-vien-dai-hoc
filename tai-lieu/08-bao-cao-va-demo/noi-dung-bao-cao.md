# Nội dung báo cáo

Gợi ý cấu trúc báo cáo:

1. Giới thiệu đề tài.
2. Mục tiêu và phạm vi.
3. Công nghệ sử dụng.
4. Phân tích yêu cầu.
5. Kiến trúc hệ thống.
6. Thiết kế lớp và áp dụng OOP.
7. Thiết kế dữ liệu JSON.
8. Thiết kế API REST.
9. Kiểm thử.
10. Demo hệ thống.
11. Giới hạn và hướng phát triển.
