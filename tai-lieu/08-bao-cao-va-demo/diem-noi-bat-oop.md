# Điểm nổi bật OOP

| Nội dung OOP | Minh chứng trong source |
|---|---|
| Encapsulation | Model dùng private fields và getter/setter |
| Inheritance | `Student`, `Lecturer` kế thừa `User` |
| Abstraction | `User` là abstract class |
| Interface | `Registrable`, `CourseValidator` |
| Polymorphism | `RegistrationService` nhận `List<CourseValidator>` |
| Exception handling | `BusinessException` và các exception nghiệp vụ |
| Collections | `List`, `Map`, `Optional` trong service |
| File IO | `JsonFileUtils` và repository file |
