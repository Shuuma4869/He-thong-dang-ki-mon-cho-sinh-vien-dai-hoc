# Hướng phát triển

- Bổ sung vai trò admin để quản lý môn học, giảng viên và lịch học.
- Bổ sung xác thực thật và phân quyền.
- Chuyển File IO sang database khi cần nhiều người dùng đồng thời.
- Thêm lịch sử đăng ký theo học kỳ.
- Thêm kiểm thử frontend tự động.
- Xuất báo cáo đăng ký theo lớp hoặc khoa.
