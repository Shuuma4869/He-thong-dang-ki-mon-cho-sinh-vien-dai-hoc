# Quy ước commit

Dùng dạng:

```text
type(scope): mô tả ngắn
```

Ví dụ:

- `feat(registration): add schedule conflict validator`
- `fix(frontend): correct course filter label`
- `docs(readme): update backend run guide`
- `chore(project): update git ignore rules`

Không commit file build, cache hoặc secret.
