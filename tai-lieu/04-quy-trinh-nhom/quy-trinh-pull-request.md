# Quy trình Pull Request

Trước khi mở Pull Request:

- Chạy kiểm tra phù hợp.
- Đọc lại diff.
- Không đưa secret vào repo.
- Không commit build artifact.
- Nếu sửa frontend, thêm ảnh giao diện.
- Nếu đổi API hoặc kiến trúc, cập nhật tài liệu liên quan.

Pull Request cần có mô tả rõ module, phạm vi thay đổi và phần chưa hoàn thiện nếu còn skeleton.
