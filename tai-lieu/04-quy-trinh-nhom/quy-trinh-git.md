# Quy trình Git

Nhóm làm việc theo nhánh riêng cho từng thành viên. Nhánh `reference/full-solution` là bản tham chiếu local của trưởng nhóm và không push trực tiếp.

Quy trình cơ bản:

1. Clone repository.
2. Tạo nhánh từ `develop` hoặc nhánh được trưởng nhóm chỉ định.
3. Commit nhỏ theo module.
4. Push nhánh cá nhân.
5. Tạo pull request để review.
6. Chỉ merge khi build/test liên quan đã pass.
