# Cấu trúc thư mục và package

Frontend được chia theo hướng feature-first:

- `src/app`
- `src/features`
- `src/shared`
- `src/mocks`
- `src/dev`
- `src/styles`

Backend dùng package gốc:

```text
vn.edu.phenikaa.courseregistration
```

Các package starter:

- `config`
- `controller`
- `dto.request`
- `dto.response`
- `exception`
- `interfaces`
- `mapper`
- `model`
- `model.enums`
- `repository`
- `repository.file`
- `service`
- `validator`
- `utils`
