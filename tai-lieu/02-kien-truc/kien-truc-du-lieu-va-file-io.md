# Kiến trúc dữ liệu và File IO

Starter định hướng lưu dữ liệu bằng JSON File IO.

Các file dữ liệu hiện có:

- `data/students.json`
- `data/lecturers.json`
- `data/courses.json`
- `data/registrations.json`

Ở starter, các file này là mảng rỗng `[]`. Repository File IO chưa triển khai đầy đủ nghiệp vụ đọc/ghi.
