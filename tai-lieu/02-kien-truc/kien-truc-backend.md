# Kiến trúc backend

Backend là Spring Boot starter dùng Java 21.

Trạng thái hiện tại:

- Có application class.
- Có cấu trúc model, service, repository, validator, controller và DTO.
- Có Spring context test tối thiểu.
- Chưa triển khai business logic đăng ký môn học đầy đủ.
- Chưa triển khai REST API thật.
- Không dùng database, JPA, Hibernate, Spring Security hoặc JWT.
