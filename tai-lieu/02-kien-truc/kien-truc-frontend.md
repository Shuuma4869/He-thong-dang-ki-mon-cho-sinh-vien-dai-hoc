# Kiến trúc frontend

Frontend là ứng dụng React single-page dashboard.

Trạng thái hiện tại:

- Routing thủ công bằng state tab.
- Dữ liệu lấy từ mock data.
- Chưa kết nối REST API thật.
- Có API skeleton để chuẩn bị phase kết nối backend.

Các màn hình chính:

- Đăng nhập demo.
- Tổng quan.
- Danh sách môn học.
- Môn đã đăng ký.
- Thời khóa biểu.
- Thông báo.
- Hồ sơ sinh viên.
