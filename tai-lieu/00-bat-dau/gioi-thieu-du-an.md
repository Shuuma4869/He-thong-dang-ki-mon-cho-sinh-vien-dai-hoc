# Giới thiệu dự án

Dự án “Hệ thống đăng ký môn học” là đồ án OOP nhóm 2 tại Đại học Phenikaa.

Starter hiện có frontend React dùng mock data và backend Spring Boot skeleton. Các phần nghiệp vụ thật như kiểm tra điều kiện đăng ký, lưu JSON File IO, REST API và kết nối frontend-backend sẽ được triển khai ở các phase sau.

Mục tiêu starter là cung cấp cấu trúc nền ổn định để thành viên clone về, chạy được frontend, build được backend bằng Maven Wrapper và bắt đầu code theo module được phân công.
