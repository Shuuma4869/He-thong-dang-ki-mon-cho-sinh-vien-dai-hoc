# Hướng dẫn làm việc với Codex

Trước khi yêu cầu Codex code, hãy đọc README và tài liệu liên quan trong `tai-lieu/`.

Quy tắc chính:

- Không tự đổi kiến trúc nền nếu chưa thống nhất.
- Không thêm dependency tùy tiện.
- Không đổi API trái tài liệu.
- Không thêm database, JPA, Hibernate, Spring Security hoặc JWT trong starter.
- Không commit build artifact hoặc file secret.
- Chạy build/test phù hợp trước khi kết thúc task.
- Không code trực tiếp trên `main`.
