# Hồ sơ nộp bài

Thư mục này lưu các tài liệu hỗ trợ nộp bài và demo:

- `so-do/`: class diagram, sequence diagram, component diagram, runtime diagram.
- `use-case/`: use case tổng thể.
- `flowchart/`: flowchart đăng ký và hủy đăng ký môn.
- `workflow/`: mô tả luồng login, course và timetable.
- `anh-demo/`: ảnh giao diện đã chụp.
- `minh-chung-kiem-thu/`: kết quả test/build/E2E dạng Markdown.

Các file `.mmd` là source Mermaid để có thể copy vào Markdown, draw.io, Mermaid Live Editor hoặc công cụ render khác. Chưa lưu ảnh export nếu môi trường chưa có renderer Mermaid.
